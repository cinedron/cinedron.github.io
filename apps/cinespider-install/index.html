03 · VIRTUAL POSITION

가상 페이로드 위치 분석

설치 공간의 중심을 X=0, Y=0으로 두고 바닥 기준 높이 Z를 지정합니다. 위치별 케이블 길이·각도와 중력만 고려한 정적 평형 장력 참고값을 계산합니다.

가상 페이로드 좌표

X는 좌↔우, Y는 전↔후, Z는 바닥↔도르래 방향입니다. 페이로드의 크기와 회전은 포함하지 않습니다.

좌표를 확인해 주세요.

05 · METHOD

천장면 기준 각도와 장력의 관계

케이블 로봇의 실제 작업영역은 공간 크기뿐 아니라 케이블 장력 범위, 프리텐션, 강성, 동적 하중과 위치에 따라 달라집니다. 따라서 도르래 높이의 일정 비율이나 임의의 각도 하나로 안전한 작업영역을 확정할 수 없습니다.

HEIGHT

75%는 참고 위치

기존 75%는 초기 검토 위치로 표시합니다. 실제 최대 운용 높이는 장비별 허용 장력, 프리텐션과 동적 안전계수가 있어야 판단할 수 있습니다.

ANGLE

천장면이 0° 기준

도르래가 같은 높이에 있을 때 천장면과 와이어 사이의 각도를 표시합니다. 0°에 가까울수록 와이어가 천장과 평행해지고 중력을 지지하는 데 더 큰 장력이 필요합니다.

LOAD

위치별 장력은 하나가 아님

네 케이블의 장력 배분은 프리텐션과 제어 방식에 따라 여러 해가 가능합니다. 시뮬레이션에는 비교 가능한 하나의 최소노름 정적 평형해만 표시합니다.

케이블 구동 시스템의 유효 작업영역이 장력 제한과 동역학에 좌우된다는 점은 wrench-feasible workspace 연구와 4케이블 정적 작업영역 연구에서도 다뤄집니다.

!

이 결과는 설치 승인이나 안전 인증을 대신하지 않습니다.

케이블 자중·탄성·마찰·처짐, 드럼 유효 권취량과 잔여 권수, 종단 처리, 프리텐션, 가속·감속, 바람, 앵커 강도 및 장비별 WLL/SWL은 포함하지 않습니다. 실제 설치 전에는 현장 측량값과 장비 사양으로 담당 엔지니어가 다시 검토해야 합니다.
